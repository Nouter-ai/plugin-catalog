# Nouter plugin catalog

Los plugins que Nouter ofrece a todas las empresas. Es un marketplace (`.claude-plugin/marketplace.json`, nombre
`nouter`): una empresa lo agrega en *Organization → Plugins & skills → Add marketplace* y sincroniza sus plugins.

| Plugin | Qué es |
|---|---|
| `delivery-salesforce` | Delivery for Salesforce, el primer stack de la línea de entrega: la plantilla de proceso «Delivery order» y las skills de cada etapa. |
